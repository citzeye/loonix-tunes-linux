# Skill Loonix Tunes

Salinan dari `../../.skill/`. Kalau skill di toolbox berubah, jalankan dari
folder `DEV`:

```
python3 .skill/sync.py loonix-tunes
```

## Wajib dibaca

| Skill | Isi |
|---|---|
| `loonix-rule` | **Baca sebelum menyunting kode apa pun.** Aturan wajib project |
| `project-structure` | Arsitektur folder dan peta proyek |

## Audio

| Skill | Isi |
|---|---|
| `audio-architecture` | Arsitektur engine audio dan alur pipeline |
| `audio-engine` | Engine: timing, decoder, seek, A-B loop |
| `dsp` | Crystalizer, EQ, normalizer, reverb, surround |
| `native-controls` | MPRIS/SMTC, mute sistem, samplerate |
| `browser-bridge` | Bridge DSP langsung ke browser |
| `mp3editor` | Modul editor MP3 (The Lab) |

## Antarmuka

| Skill | Isi |
|---|---|
| `qml` | Panduan QML |
| `ui` | Komponen: core, tab, theme, scroll, playlist |
| `core` | Konfigurasi, library/tab, deteksi wireless |
| `pref` | Preferensi, matugen, laporan bug, theme editor |
| `keyboard` | Pemetaan keyboard dan shortcut |
